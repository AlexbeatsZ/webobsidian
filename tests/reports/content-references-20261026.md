# 稳定内容引用与嵌入原位编辑

## 范围

用户批准前轮设计，并授权 Sol 并行实现。三个 Sol 分别负责核心结构目标、现有全库索引与剪贴板、
嵌入源会话编辑；父负责跨模块契约、未保存覆盖、命令与补全、设计文档和集成验收。
开始时 tracked tree clean，仅有无关 `.workbuddy/`；没有修改真实 Vault、安装目录或发布包。

## 交付结构

- `contentTargets` 复用现有 MarkdownModel、公式与结构容器，提供缓存的类型目标、保护范围和创建编辑。
- `[[^heading-ID]]` 等全库目标与旧 `[[#^ID]]` 文档内引用明确区分；文件路径解析器不猜测全库目标。
- VaultCatalog schema 4 持久化定义/错误元数据，复用原有索引生命周期与反链依赖失效；重复不选首个。
- 未保存会话覆盖磁盘索引；干净但过期的缓存不遮蔽磁盘移动或冲突。缺失保留错误，不创建伪文件。
- 命令创建/复用类型身份并复制引用；`[[^` 补全显示标题/路径，插入身份。
- EmbedProjection 映射局部增量到唯一源 DocumentSession，使用源历史、保护标识和结构边界；不整段覆盖。
- 嵌入可原位编辑并沿用自动保存；消失/歧义/移动实时更新。循环按文件与片段组合识别，不禁止所有同文件嵌入。
- 复制完整定义时产生新 ID，重映射语义引用而不替换代码字面量；有效剪切首次移动保留 ID，重复粘贴生成新身份。
- 打印和执行受限预览递归剥离编辑能力；普通表格等原有局部草稿仍用原有提交路径。

## 边界

没有批量迁移真实旧笔记、生成安装包、安装新版本或发布 Releases。
剪贴板浏览器验收为 ClipboardEvent/DataTransfer，输入法为合成事件；不是实体系统剪贴板、物理 IME、
原生 Electron、安卓/macOS 或长期稳定性验收。原安装 0.1.27 不包含本次改动。
跨窗口/刷新后的剪切 token 不再可信时按复制生成新 ID；外部原始文本粘贴保留原文并诊断重复。
现有独立文件引用、标题、普通块和脚注兼容入口仍保留；未自动改写历史公式名称。

性能边界：目标解析按文档模型缓存，索引依赖按目标 ID 失效；未声称全库性能提升。
补全候选上限 20，并逐个经共享解析验证以排除未保存冲突；没有引入第二份权威目标索引。
