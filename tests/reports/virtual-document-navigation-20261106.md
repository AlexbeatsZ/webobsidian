# 连续文档导航、标题与侧栏验收

用户要求修复大纲跳到章节开头后上滑的随机跳动，并共用普通笔记排版；增加目录大纲入口、分层折叠、聚合缩略图及不可绘制区域留白。

## 设计与实现

设计来源见 `docs/design/virtual-documents.md` 的“2026-11-06 标题、目录、大纲与缩略图约定”和“滚动与异步高度测量”。
首页与文件交界使用同一 `MarkdownView` 原生文件标题；首页副标题和目录是原生 H1/正文列表。
章节改名通过已有文档路径迁移和 Vault 写入，同步当前配置中所有分组的来源路径，失败回滚；JSONC BOM、注释、换行与无关字段保持。
大纲的文件/标题/PDF 书签分别折叠；缩略图复用当前来源的会话，公式等区域保留空白。

实测确认并修复了两个 Markdown 高度错误：

- 全章就绪不能使用 `[role="status"]`：公式也会持有它，曾阻止前章真实高度上报。
- 缓存会话重挂载不代表编辑器已经创建：CodeMirror 就绪前的空宿主曾把长章高度污染成约 81px。

只有整章初始化使用 `data-virtual-loading`；标记移除重测，测量包含边框。待定补偿执行前先计入用户真实滚动增量，避免覆盖新滚动。
长 PDF 导航在未提交高度表上换窗、重捕锚点偏移会重复计算程序位移；导航期间锁定目标与邻章窗口、来源和偏移，真实输入后释放。
原生上滑还精确捕获 CodeMirror 测量主动修改外层 `scrollTop` 的 511.5px 补偿；通过公开 `requestMeasure` 与合并后的微任务报告布局位移，前序来源不再作为用户滚动重复计入。
