# Markdown full-document minimap and fixed right sidebar

## Implementation

- Fixed right ribbon now has a persistent `minimap` selection, restored through the existing store workspace state. Existing binary-file guards are retained. Left ribbon and dynamic tab lifecycle are unchanged.
- Right outline uses shared Markdown session heading metadata or the active matching PDF session's embedded outline. Right thumbnails use the Markdown minimap or PDF owner's PdfThumbnailsPanel, sharing the viewer's session rather than opening another PDF.
- MarkdownMinimap reads DocumentSession.analysis and the main view's CodeMirror Text. No second editor, Markdown parser, formula renderer, script execution, document writer, registry or search request is introduced.
- Canvas backing is bounded to512x2048pixels, samples at most682text/structure rows across the entire source, and slices at most180characters from each sampled line. Formula/image/code/table blocks use structural strokes rather than exact rendered screenshots. Full document source-line distribution includes content outside CodeMirror's DOM viewport.
- Document version, canvas dimensions, theme and shared search results invalidate drawing. Ordinary scroll/selection updates only schedule a requestAnimationFrame viewport-box update; no React scroll state or canvas repaint.
- Main-only lookup uses fragmentNavigation.navigationView(path,'main'), excluding same-path side/split/fragment editors. The existing registry now exposes subscribeNavigationViews; its existing ViewPlugin publishes notifications. navigationViewport shares captureLocation's source-offset/lineBlockAtHeight calculation. Existing navigation consumes scrollOnly to preserve cursor/selection/source-reveal/highlights while retaining fold/scroll routing. Drag jumps are coalesced to one per frame, with document history disabled.
- Workspace search consumes parent's search.ts getSearchResultHighlights/subscribeSearchResultHighlights and NoteMatches.sourceRanges. Each range must still equal current CM sliceString(from,to), so stale saved coordinates are omitted after draft edits. No duplicate matching or reliance on truncated20context snippets.
- In-document find uses the actual CodeMirror SearchQuery.getCursor, including regex/case/whole-word semantics. Dense results merge by minimap pixel across the full document: each query restart skips only already represented source-line bins. It does not stop after the first20000matches. Workspace hits are horizontal bars, local-find hits are right-edge marks.
- Subscriptions, observers, pointer capture and pending animation frames dispose on path/panel teardown. PDF owner retains all PDF resource/lifetime ownership.
