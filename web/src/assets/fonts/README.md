# Document fonts

Binary font data extracted unchanged from the user's STEM snippets:
Fonts-MathJaxMain.css, Fonts-MathJaxMath.css, Fonts-NotoSerifSC.css, Fonts-CascadiaCode.css.
Face family/weight/style mappings preserve those declarations.
Noto Serif SC retains full regular/bold coverage (about 29.6 MB combined).

Upstream licenses included: Noto CJK Serif (SIL OFL), Cascadia Code (SIL OFL),
MathJax 2 TeX fonts (MathJax distribution Apache 2.0 license).
Sources: https://github.com/notofonts/noto-cjk/tree/main/Serif ,
https://github.com/microsoft/cascadia-code , https://github.com/mathjax/MathJax/tree/2.7.9 .
