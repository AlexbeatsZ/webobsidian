# 文档阅读、大纲与缩略图

## 第一版范围

- PDF 在应用内只读查看，不进入 Markdown DocumentSession，也不参与文本保存。
- 大纲和固定的“缩略图”入口均位于右侧栏；左侧固定入口不变。
- Markdown 大纲继续使用 DocumentSession.analysis 的标题；PDF 使用文件内置目录和目的位置。没有目录时明确提示，不把页列表伪装成目录。
- Markdown 缩略图展示全文分布和当前视口，支持点击、拖动视口定位；PDF 缩略图按页排列，标记当前页，点击跳页。
- 搜索结果在缩略图中可见。正文和缩略图必须使用相同查询语义、匹配结果和位置数据，不能另写一个简化搜索导致命中不一致。
- 扫描 PDF 没有文字层时仍可阅读和翻页，但不承诺 OCR 或自动生成目录。

## 现有归属及复用约束

- 文本源、草稿、Undo、语法分析仍属于 DocumentSession / markdown-core；新增导航面板不得拥有第二份可写文档。
- Markdown 已有视图与导航归 activeEditor / fragmentNavigation；迷你地图不能另建键盘或源码坐标体系，不能误跳同路径侧栏嵌入。
- 既有搜索面板的结果以及编辑器原生查找状态是 Markdown 命中的来源；缩略图只是消费，不发起重复索引或搜索请求。
- PDF 解析归同一个本地 PDF.js 文档资源；阅读页、目录、文字内容及缩略图共享该资源。不得再用原生 iframe 启动另一份工作区。
- 附件地址继续使用既有 Vault 身份范围。二进制文件不能触发文本响应验证，也不能因缺少文本响应字段误判为切库；真实身份冲突仍阻止写入。

## 性能及生命周期验收

- 不为 Markdown 缩略图挂载整篇第二编辑器，不执行其中脚本，不重新渲染整篇公式；复用已分析文档，以有界分辨率呈现全文概览。
- 第一版 Markdown 采用文字采样和结构色块，最多512×2048画布、682采样行；公式/图片/表格不是像素级截图。PDF正文与缩略图共享页面资源及命中框，渲染并发2，文字页缓存48页；匹配框按文字片段比例估算，不承诺复杂字形精确边界。
- 文档、宽度、主题或匹配结果变化才重绘概览；普通滚动只更新视口位置，合并到动画帧。
- PDF 大图与缩略图按可见范围请求，限制同时渲染数与 canvas 大小；不能按文档页数同时分配高清 canvas。
- 切文件、关闭面板和卸载时取消旧任务、清理监听器和资源，晚到结果不能覆盖新文档或销毁已转交的新宿主。
- 性能报告区分结构性限制与实测结果；未测延迟或内存时不声称性能提升。

## 必须覆盖的验证

正文/PDF/右侧大纲/缩略图来回切换；无目录、损坏文档、无文字层、较多页面；快速换文件和卸载中的异步结果；当前页及页码跳转；命中显示与清除；Markdown 草稿、Undo、滚动和拖动不写源码；窄窗及明暗主题；真实旧 Vault 身份被拒绝而 PDF 查看不再误触发失效。打包 worker 和资源路径必须在隔离生产构建中核对，开发服务器通过不等于安装包通过。
