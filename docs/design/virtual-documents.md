# 虚拟文档

2026-11-05 用户决定保留独立 Markdown 章节、PDF 与课件，在阅读时把一组文件当作连续文档。
禁止为此物理拼接教材。2026-11-05 用户补充：连续页面里的每章直接编辑，沿用各真实文件自己的保存、Undo、冲突和引用身份。

## 配置与呈现

- 每个资料文件夹的 `.virtual-document.json` 是唯一配置来源，随文件夹移动、复制和原生同步。
- version/title/streams；分组有稳定 id、标题与按顺序列出的文件夹相对路径。MD 与 PDF 可分组，避免重复阅读同一内容。
- 文件夹右键启用/停用，自动发现 Markdown 与 PDF，排除旧索引。可编辑隐藏配置指定顺序和分组。
- 文件树和快速切换器投影成一个文档入口；内部目录索引、引用、搜索仍保持真实文件身份。
- 配置使用现有 Vault 写入、revision 与身份保护；拒绝绝对路径、父级穿越、隐藏来源、重复来源及不支持类型。
- 非法配置报告错误，普通文件夹和全部源文件仍可访问。
- 无额外顶部栏或显示源文件入口。右下角状态栏显示当前分组，菜单包含全部分组及独立的“配置”选项；Markdown 默认组名为 MD，PDF 为 PDF。
- “配置”在当前虚拟文档中编辑隐藏 JSON，使用 JSON 语言高亮。保存前校验结构、路径和来源，错误草稿保留；合法保存刷新分组后仍停留在配置，不重建正在编辑的会话。
- 文件树、文档标签和编辑器右键提供系统文件管理器定位；文件夹打开目录，文件显示其所在位置。桌面 IPC 校验原生主窗口、当前 Vault 和实际路径。

## 阅读与生命周期

- 首页索引运行时生成，不增加 Markdown 索引文件。每个源文件是一级大纲，其标题/PDF 书签作为下级。
- 首页文档名复用普通文件标题，分组名使用原生 Markdown H1，索引使用原生正文列表。文件交界使用同一个文件标题组件与编辑行为；改名通过真实文件身份操作，并同步所有分组中该来源的相对路径。首页文档名编辑更新描述文件 title，不改目录名。
- 大纲首项“目录”返回首页；各文件与有下级的标题独立折叠，折叠箭头与文字跳转分开。
- 缩略图支持目录和全部成员的导航，当前章节复用普通 Markdown minimap 或其已打开的 PDF 会话分页缩略图；不为侧栏预览额外打开整本来源。公式等无法直接绘制的内容保留空白，不画强调色占位框。
- 同一滚动容器按邻近窗口挂载源文件；高度占位与测量修正保持当前锚点。边界前预读，关闭/换库取消晚到结果。
- Markdown 按源文件加载与解析。窗口内为独立、可编辑的共享 DocumentSession；未编辑章节用临时租约，卸载时释放，已经编辑的章节保留各自的历史与未保存/冲突草稿。普通标签、嵌入等持有同一会话时不释放。
- PDF 复用 PdfResource、任务队列、页面可见性、文字层及释放。只打开邻近文件，只挂载可见页面 canvas。
- 每份内容保留真实 sourcePath，图片相对地址、公式及全局内容 ID 不变。焦点对应实际章节；状态栏视图模式、保存、撤销与插件编辑命令使用当前章节身份，分屏身份仍为所属页面。
- 大纲先用保存索引的轻量元数据；打开的草稿提供实时标题。跳转由源路径+标题/页码定位，避免不稳定的全书字符偏移。
- 成员文件名与别名聚合到选择器入口；全文搜索继续返回真实源文件，不把整本拼成一份搜索文档。
- 既有单份大文件的 100,000 字符正文索引限制是独立问题，不以虚拟阅读交付代替完整检索验收。

## 2026-11-06 标题、目录、大纲与缩略图约定

这些是用户指定的共用行为，修改此模块前先读本节；不要再为聚合页另做一套近似排版。

| 内容 | 采用的实现与行为 |
| --- | --- |
| 首页“物理化学 第三版”等文档名 | `MarkdownView` 的原生 `.cm-inline-title`；与普通文件标题共享字体、字号、字重和编辑交互。编辑只改 JSON 的 `title`，不重命名资料文件夹。 |
| 首页“MD / PDF / 自定义分组”等副标题 | 原生 Markdown H1，复用普通笔记的标题规则。 |
| 首页目录列表 | 原生 Markdown 正文有序链接列表；运行时生成，不落地新的 Markdown 文件。链接跳到聚合滚动区域的真实来源。 |
| Markdown 文件交界标题 | 真实章节自己的原生文件标题；不能再增加一个样式不同的 `h2` 或独立标签。PDF 文件标题也使用同一标题行。 |
| 重命名文件标题 | 重命名真实文件，并局部改写当前 `.virtual-document.json` 所有分组内引用该文件的相对路径；禁止仅改显示标签导致目录和真实文件脱节。 |
| 大纲 | 第一项“目录”回到首页。每个文件及有子项的标题/PDF 书签提供独立折叠箭头；文字仍跳转，折叠状态在同一阅读会话切换侧栏后保留。 |
| 缩略图 | 包含目录与各文件导航；当前来源使用现有 Markdown minimap 或正文登记的 PDF 分页会话。无需为侧栏预先加载整本书。 |
| 缩略图中公式等不可绘制内容 | 保留原位置的空白，去掉紫色/强调色占位框。正常文字、标题和搜索匹配标记继续使用已有绘制方式。 |

标题改名使用原有 Vault 身份与文档会话路径迁移。配置有未保存草稿、保存中或冲突时先处理配置，不能越过草稿覆盖 JSON。
服务端在移动前核对配置 revision，最终写入再按 revision 比较；写入失败则回滚文件名，保留外部配置。JSONC 的 BOM、注释、换行及无关字段保持。
此同步只适用于聚合文档内的标题改名；在其他工具中单独增删/移动成员仍需更新描述文件，不宣称监听任意外部重命名。

## 滚动与异步高度测量

- 阅读位置以真实来源序号和来源内偏移表示。来源正文异步展开、公式完成或邻章卸载后，按测量高度补偿前序布局变化。
- 执行待定补偿前必须先纳入真实 `scrollTop` 的增量；不能把用户刚发生的滚动覆盖为先前位置。用户开始滚动时取消尚未执行的导航帧与持续标题定位。
- 导航锁定期间没有新的真实滚动输入，程序定位和浏览器因布局收缩而钳制的 `scrollTop` 不得累加到用户偏移；新导航同时重置滚动基线。否则连续两次前序高度补偿会把首次程序位移重复计入锚点，长 PDF 可落到前一份文件末页。
- 锁定期间保持目标及前后邻章的挂载窗口，不用尚未测量一致的高度表换窗；锚点的来源和偏移均不从瞬时 DOM 重捕获。真实用户滚动解除锁定后再恢复常规窗口更新。
- PDF 单页尺寸变化与前序文件高度变化需协调：前序 PDF 的整份高度交给聚合锚点补偿，当前 PDF 自然阅读时的页内尺寸补偿需同时更新聚合偏移/滚动基线；导航中以请求的来源/页为准，不能让分页和整章各独立修改滚动位置后再次相加。
- CodeMirror 在近期 wheel/touch 或焦点编辑器的测量结尾会自行调整外层滚动容器。章节用公开 `requestMeasure` 在测量前记录基线、测量后的单个微任务中报告程序位移；同一同步测量的多轮 read/write 合并，只取最早基线。前序章节的这类补偿不能算成用户滚动，当前章节的自然阅读则同步更新内偏移；销毁的编辑器不得回调。不要通过更改 CodeMirror 私有 `inputState` 或屏蔽默认滚动规避。
- 文件交界附近优先保留接下来可见的文件标题作为锚点；前章还未载入时不能锚到它尚不存在的正文位置。
- 只有整章加载占位元素使用 `data-virtual-loading`。不能用宽泛的 `[role="status"]` 判断整章就绪：公式也会使用该 ARIA 角色，曾因此阻止前章高度上报，导致跳转后停在前章末尾。
- 加载标记移除时需要立即重测；测量包括章节边框。不要只在来源初次挂载时估算高度。
- 复用已缓存的文档会话不代表编辑器已挂载：`MarkdownView` 在副作用中创建 CodeMirror，短暂空宿主也必须标记整章未就绪，等 `onReady` 后移除并重测。否则会把实际长章节错误记录为只有外边距的约 81px，窗口切换时整段跳走。
- 导航、侧栏点击、缩略图行/页跳转和真实滚动共用来源身份；不要引入整本拼接后的字符偏移。

`tests/browser/virtual-navigation.spec.ts`（目录、大纲折叠、MD/PDF 缩略图）、`tests/browser/markdown-minimap.spec.ts`（既有缩略图生命周期），

## 已知边界

- 文件顺序是描述文件中的显式列表。目录整体移动时相对路径仍有效；聚合标题改名会同步此配置，外部单独增删、改名或移动成员仍需更新配置，缺失成员显示错误。
- PDF 文件名立即进入目录；内部书签在邻近文件打开后补入大纲，不为收集书签预先打开所有 PDF。
- 现有通用文件改名在服务端成功后若 HTTP 应答丢失，不会自动完成客户端会话路径迁移；磁盘来源与 JSON 已保持一致，但需刷新目录并打开新路径。配置冲突回滚测试不等于成功后丢应答恢复测试。
- 现有插件兼容层启动时仍会扫描 Markdown 元数据；虚拟阅读不再额外把未编辑章节存入永久 DocumentSession 注册表。
- 相邻章节异步展开会改变目标前面的布局。导航锚点使用来源序号和内部偏移；真实滚动输入前不得被布局引发的 scroll 事件替换成相邻来源。
- 构建共享 core 后再运行依赖这些产物的测试。并行重写 core dist 会导致单元读取半更新导出，或 Vite 热更新重置正在验收的工作区。
