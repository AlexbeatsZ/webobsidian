# 稳定内容引用

## 目标与所有者

引用身份与文件路径、标题文字分离。`[[^heading-ID]]` 链接和
`![[^heading-ID]]` 嵌入指向 Vault 内唯一目标；旧文件、标题、块和脚注语法保留兼容。
真实 Vault 不自动迁移，不因查询缺失内容目标而创建文件。

2026-10-30 清理：运行时不再将 `> **文字**` 解释为特殊小标题，也不再通过
`#-文字` 查找这类目标。原生正文标题 `#######` 和全库类型身份是替代实现；
JS 大纲直接使用统一 headings 元数据。旧小标题的识别和范围解析仅从独立
`markdown-core/migration` 入口提供给离线迁移/恢复。普通文件、标题、
非类型块链接和脚注仍是有效语法，不因“旧”而删除。

使用入口：命令面板的“复制稳定内容引用”“复制可编辑内容嵌入”在当前标题、公式、
代码或 Callout 上复用/创建身份并复制语法；选中完整块后用“将选中完整块创建为范围引用”。
输入 `[[^` 或 `![[^` 可按 ID、标题和文件查找已定义的全库目标。
已知来源文件时，输入 `[[文件名^` 只列出该 Markdown 文件中已定义身份的目标；
在 `^` 后继续输入标题、公式标签或 ID 筛选，例如 `[[热力学^eq-`。嵌入使用 `![[热力学^`。
同名文件请使用带文件夹的路径，如 `[[物化/热力学^`；文件缺失或歧义时不回退全库候选。
用上下键选择、Enter 确认后，自动写入 `[[^类型-ID]]`（嵌入保留 `!`）。
文件名前缀只是查找范围，不保存成路径约束，因此后续改名或移动仍然有效。
尚未有 ID 的内容需先在源内容使用“复制稳定内容引用”，不会仅因浏览候选而修改笔记。
嵌入悬停时左上角铅笔进入内容编辑，右上角为“打开链接”和 `</>`（展开 `![[…]]` 链接源码，与其他块的 `</>` 相同）。
内容编辑与 `</>` 一致：没有“完成”按钮，焦点离开嵌入或按 Esc 即回到渲染；外部点击要等指针松开后再切换，
否则 CodeMirror 在 mouseup 按新布局重算光标会落到错误位置。编辑挂载完成时不得把已聚焦的编辑器节点暂时移出 DOM，
否则会被当成失焦。窗口切换不退出编辑。编辑是增量写入，退出只卸载编辑视图，不保存旧片段覆盖原文。

- markdown-core 的内容目标解析拥有 ID、类型、边界与创建编辑；沿用现有语法模型。
- VaultCatalog 拥有已保存目标索引，复用现有更新、移除和重建生命周期。
- DocumentRegistry 中的未保存会话覆盖磁盘索引；干净但过期的缓存会话不能遮蔽磁盘上的移动或冲突。
- DocumentSession 仍是正文、历史和保存的唯一所有者；嵌入只投影视图。
- 现有导航、补全、预览和 MarkdownView 消费同一目标；不增加独立解析器或保存管理器。

## 语法和边界

- `heading-`：标题末尾 ID；跳转聚焦标题，嵌入覆盖到下一个同级或更高级标题。
- `eq-`：沿用公式的严格锚点绑定；历史公式名称不隐式重写。
- `code-`：完整围栏代码块，不按相邻段落缩进推断。
- `callout-`：完整 Callout 语法容器；其结构仍受 Markdown 引用前缀影响。
- `table-`：表格后空一行、同一引用容器前缀下的独立 ID 行。紧贴表格的行会被 GFM 当作表格行，不能挂 ID。
- `html-`：HTML 块后空一行的独立 ID 行。HTML 块延续到空行为止，紧贴的 ID 行会被吞进 HTML 块。
- `range-`：独立行 `^range-ID:start` 和 `^range-ID:end` 明确包围完整块。

种类名单只在 markdown-core `links.ts` 的 `CONTENT_TARGET_NAMESPACES` 定义，链接识别、片段解析和
目标校验都引用它；不在各处重复写正则。

## 块角落按钮

公式、表格、代码块（含 Mermaid 与 HTML 预览）、Callout 和 HTML 块悬停时，右上角在 `</>` 前显示：
剪贴板复制显式引用 `![[^id]]`，link 复制隐式引用 `[[^id]]`。与命令面板“复制稳定内容引用/复制可编辑内容嵌入”
共用 `contentReferenceCommands.ts` 的 `copyContentReference(view, range, embed, kind)`：已有身份直接复制，
没有则用 `createContentTarget` 创建一次（一个事务，可撤销）。只读视图只复制已有身份，需要新建时提示。
片段/嵌入视图不显示按钮（身份属于源笔记）。表格内公式、闭合行后还有正文的公式不能引用，不显示按钮。

按钮组 `.cm-block-controls` 由 `blockControls.ts` 统一创建，`</>` 仍由 `sourceControls.ts` 提供并放进同一组；
复制会用到 store，而 store 的导航链依赖 sourceControls，所以按钮组不能放进 sourceControls（会形成导入环）。
与 `</>` 一样只在悬停对应块时出现：整块 widget（公式、表格、Mermaid、HTML）悬停整块即显示；
代码块和 Callout 仍是可编辑文本行，按钮挂在首行行尾，由 `.md-code`/`.md-callout` 块包装器的悬停显示，
Callout 的按钮与标题行的公式 `</>` 共用同一个控件。代码块和 Callout 的按钮在点击时按自身 DOM 位置找所属块，
上方编辑不会重建它们。按钮只在创建 DOM 时生成，点击时才计算身份，不增加每次输入的工作。
窄表格上按钮组以不透明底色盖在表头右上角：表格上方是列拖动手柄，右侧是加列按钮，都不能占用。

范围允许完整嵌套，禁止交叉、缺失配对和切断结构；代码等字面量里的标记不生效。
重复、错误类型或无效范围必须失败关闭，不能选第一个或退回普通块推断。
移动保留身份，复制需要新身份并重映射副本内引用。

## 编辑与性能

嵌入编辑按源会话版本映射局部增量；不得失焦时以旧整段覆盖原文。
光标、选择和滚动为视图私有，撤销归源会话。身份标记和范围边界受到保护；
目标消失、结构无效或编辑版本变化时停止写入。执行受限预览和打印不能获得写能力。
循环嵌入沿用已有递归保护。普通展示保持轻量，用户明确进入编辑后才挂载编辑视图。
解析按不可变模型缓存，索引随文件更新，不按每次光标移动重建全库。

创建范围时标记与内容用空行分开，边界必须能被核心识别成独立块。
复制/剪切通过编辑器共享剪贴板策略处理，只有完整目标定义才重映射身份；代码字面量不替换。
普通外部文本粘贴保留原文，重复身份进入冲突状态，不静默改变来源不明的引用。
旧笔记的批量迁移不自动执行：歧义目标必须由人确认后才能重写。

## AI 引用(MCP)

AI 通过 `obsidian_find_targets` 查询真实 ID 后写 `[[^id]]`/`![[^id]]`,不猜 ID。新公式可直接写语义 ID
(`$$ ^eq-mass-energy`),无需随机串;提议修改时服务端校验新 ID 全库唯一且挂在对应结构上。详见 native-mcp.md。
