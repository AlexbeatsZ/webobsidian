# 文档媒体与嵌入主题

## 基准与范围

以 STEM `.obsidian/snippets/Theme.css` 中启用的规则为基准，迁移到已有组件与默认样式定义。
不加载旧片段，不另设覆盖主题。注释中的试验规则不视为需求。
编辑、阅读、表格片段、嵌入、Canvas 与分享客户端共用组件；打印挂载相同的只读组件。

## 前景色与主题作用域

- `obsidian.css` 在 `:root` 提供默认浅色变量；显式 `.theme-light` / `.theme-dark`
  容器声明文字颜色，不能只在其祖先 `body` 中引用容器内部的变量。
- `App` 在布局 effect 中同步 `body` 的主题类，切换前移除旧主题，卸载时恢复原类。
  插件 Notice、Modal、菜单和补全直接挂到 `body`，因此也能取得同一套主题变量；
  React 内部主题容器保留，供桌面标题栏观察和独立文档宿主使用。
- 原生 button/input/select/textarea 默认继承文字颜色；按钮强调色与语义色仍由组件决定。
- CodeMirror 搜索面板、提示、文本框和按钮直接使用应用的语义颜色变量；
  不依赖 CodeMirror 默认浅色皮肤，也不为主题切换重建文档或编辑器。
- 2026-10-22 本轮仅执行静态检查和隔离生产构建；真实明暗切换、控件和插件浮层
  的视觉验收仍由用户完成，未启动浏览器、Electron 或服务器。

## 图片

- Markdown 图片目的地址使用已有 MarkdownModel/Lezer Image 与 URL 范围，不能遇到第一个
  `)` 就截断：SVG data URL 中的 `rgb(...)`、字体/路径等可以包含配对括号。逐行兼容已有
  含空格的 Vault 文件名，但有效语法节点的目的范围优先；同排判断也消费完整图片范围。
- 拖拽改尺寸复用该完整范围定位图片，只对 alt 源码范围打补丁；地址、可选标题和
  data payload 原字节保留，不能用旧的首个右括号正则重建整个图片。
- `data:image/svg+xml`（百分号编码或 base64）作为普通 img 加载，沿用共享图片宿主、
  源码保留、尺寸与测量生命周期；data 地址不参与文件名/片段展示约定，避免把 payload
  内的 dark/Wiki、颜色片段等字符串误当主题标记。
  SVG MIME 复用原有 SVG 展示标记，不另建内嵌 SVG/HTML 执行路径。2026-10-23 仅源码
  差异检查，未运行测试、构建或 UI/运行验收。

- 组件保留原始目标、说明、尺寸与展示标记，和 API 解析后的加载 URL 分开。
  URL 变成 `/api/raw?...` 或分享专用 URL 后，文件名/片段约定仍然有效。
- `![[图.png|说明|宽度]]`、`![说明|宽度](图.png)` 和净化后的 HTML 图片使用同一展示逻辑。
  只有尺寸时不把数字当作说明；仅改说明也必须刷新 widget。
- 说明使用底部居中、`0.65rem`、`1.2` 行高和 `0.5rem` 上间距。保留原有判定：
  空 alt 与以 `.jpg`/`.png` 结尾的 alt 不显示说明，未擅自扩展到其他扩展名。
- 同一源码行只有图片时同排、底部对齐。CodeMirror 在 widget 之间插入光标占位 img，
  直接复用 `display:table/table-cell` 会形成匿名表格行，导致上下堆叠；使用 flex 行实现
  相同的对齐意图，保留占位节点。混合正文与进入源码编辑的行保留通常的行布局。
- 保留 `#center`、`#full`、`#x1.5`、`#x2`、`#x0.5`，以及目标中包含 `dark`/`Wiki` 的约定。
  SVG 保持自然宽度、不受最大宽度约束；缩放时拖拽将屏幕坐标换算回源码像素尺寸。
- 浅色正文：`invert(100%) contrast(130.77%) hue-rotate(180deg)`；浅色 Callout 位图：
  `invert(100%) contrast(125.6%) hue-rotate(180deg)`；暗色 Callout 位图：
  `brightness(1.233) contrast(1)`。`dark`/`Wiki` 的反色/豁免使用原定义。
  打印时取消这两类标记图片的反色。规则限于文档图片组件，不影响工具栏图标。

## 嵌入与宽度

- 去掉文件名标题、边框、额外内边距和 400px 内部滚动上限。
- 嵌入片段第一个正文标题隐藏，后续标题保留；标题源码与片段起始坐标不变。
- 嵌入仍只读、订阅源笔记草稿，循环/深度限制不变。长内容仍可由 CodeMirror
  虚拟化，通过外部文档滚动查看，不能把“无内部高度上限”等同于“所有行始终在 DOM”。
- 表格、HTML、Callout 与块公式的外壳使用 `width:fit-content;min-width:100%;max-width:none`。
  普通文本正常换行，宽表格可以按固有最小宽度展开。
- 表格内层 `cm-table-frame` 跟随实际表格宽高；添加行/列与源码按钮以该层定位，
  不能以满栏宽度的外壳定位。表格外部纵向空隙用 padding 纳入编辑器高度测量。
- Callout 正文保留原始 CodeMirror 文本行，外框只作包装装饰。纵向间距不用行间 margin：
  外层用 16px padding，正文包装层用 8px 顶部 padding，标题竖线仍从 top:0 到 bottom:0。

## Mermaid 与特殊生成内容

- Mermaid 使用相同正文字体链、16px 字号，并在字体就绪后计算标签尺寸。
- 正文节点底色为第二层、连线标签底色为第一层；Callout 内分别为第三层和第二层。
  文字随明暗主题取纯黑/纯白，切换主题不依赖重新解析图表。
- Obsidian 的 `--mm-*` 反色补偿不适用于本项目，直接使用最终色值与现有主题变量；
  不对整张图执行反色。生成器自带 SVG stylesheet 的槽位通过组件样式覆盖。
- 保留 `.chem-cell` 生成 SVG 的 1.2px 化学键和浅色/打印滤镜兼容样式。
  当前没有化学结构生成器，且用户原始 HTML 的 SVG 仍按统一策略净化，不开放任意 SVG。
- 当前没有 PDF.js 阅读器，PDF canvas 反色规则没有可作用的组件，未伪造 PDF 迁移完成。
  Dataview/exTable 等插件专用容器也未实现；通用表格/HTML 容器已采用宽度规则。
- Hider.css 的侧边栏/标签栏/PDF 工具栏交互属于外层 UI，另行处理。

## 验收

隔离图片固定资源检查说明、同排、尺寸、别名更新、缩放拖拽/撤销、明暗滤镜、
SVG 与居中；长笔记检查隐藏首标题、后续标题、外部滚动及草稿订阅；真实 Mermaid
检查明暗与内外层配色；宽表格与打印检查固有宽度、说明和只读控件。保留源码比对，
检查后查看截图。浏览器自动化不代表用户实际笔记或原生打印对话框验收。
